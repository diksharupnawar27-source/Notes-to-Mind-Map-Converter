The Transformer is a neural network architecture that relies on self-attention instead of recurrence. The encoder reads the input sequence and builds contextual representations. The decoder generates output tokens one at a time using the encoder context. Self-attention lets every token weigh every other token in the sequence. Multi-head attention runs several attention operations in parallel. Positional encoding injects word order information into the embeddings. Pre-training teaches the model language patterns from large unlabeled text. Fine-tuning adapts a pre-trained model to a specific task such as classification. BERT is an encoder-only model used for question answering. GPT is a decoder-only model used for text generation. T5 is an encoder-decoder model that treats every task as text-to-text.
