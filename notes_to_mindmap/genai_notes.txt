Generative AI is a branch of artificial intelligence that creates new content such as text, images, audio and code. Generative models learn the statistical patterns of their training data and then sample new examples from those patterns. Discriminative models, in contrast, learn to separate classes instead of creating new data.

Large language models are neural networks trained on huge text corpora to predict the next token. The Transformer architecture is the foundation of modern large language models. Self-attention lets every token weigh every other token in the sequence. Multi-head attention runs several attention operations in parallel to capture different relationships. Positional encoding injects word order information into the embeddings. The encoder reads the input sequence and builds contextual representations. The decoder generates output tokens one at a time using the encoder context.

BERT is an encoder-only model used for classification and question answering. GPT is a decoder-only model used for text generation. T5 is an encoder-decoder model that treats every task as text-to-text. Tokenization splits raw text into subword units that the model can process. Embeddings map tokens and sentences to dense vectors that capture meaning. Cosine similarity measures how close two embedding vectors are in meaning.

Pre-training teaches a model general language patterns from large unlabeled text. Fine-tuning adapts a pre-trained model to a specific task using a smaller labeled dataset. Instruction tuning trains a model to follow natural language instructions. Reinforcement learning from human feedback aligns model outputs with human preferences. Parameter-efficient methods such as LoRA fine-tune only a small number of extra weights.

Prompt engineering is the practice of writing inputs that guide a model toward the desired output. Zero-shot prompting asks the model to perform a task without any examples. Few-shot prompting includes a handful of examples inside the prompt. Chain-of-thought prompting asks the model to reason step by step before answering. Temperature controls how random the generated text is, with low values giving more predictable output.

Retrieval-augmented generation combines a language model with an external knowledge base. A retriever finds the passages most relevant to the question using embedding similarity. The generator then writes an answer that is grounded in the retrieved passages. Retrieval-augmented generation reduces hallucination because answers rely on real documents.

Hallucination is when a model produces fluent but false or unsupported statements. Bias in training data can cause models to produce unfair or harmful outputs. Evaluation of generative models uses metrics such as perplexity, ROUGE and human ratings. Responsible use of generative AI requires privacy protection, transparency and human oversight.

Diffusion models generate images by gradually removing noise from a random starting point. Generative adversarial networks train a generator and a discriminator against each other. Variational autoencoders learn a compressed latent space from which new samples can be drawn.
